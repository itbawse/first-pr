# first-pr

Practice repo for my first pull request.

## What's here

This repo exists to learn the GitHub pull request workflow:

1. Create a branch for a change.
2. Commit the change on that branch.
3. Push the branch and open a pull request.
4. Review and merge it into `main`.

## Contributing

Make changes on a new branch rather than committing directly to `main`, then open a pull request.
